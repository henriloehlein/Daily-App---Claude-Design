# Prototypen

Wegwerf-Prototypen, um den **Spaß** einer Idee zu testen, bevor gebaut wird. Kein Backend, kein sauberer Code, meist eine einzige HTML-Datei, die im Browser oder auf dem Handy läuft.

- Ordner pro Prototyp: `NN-kurzname/` (Nummer = Idee)
- Ergebnis des Tests (Wer hat gespielt? Wie lange? Wollte man nochmal?) unten in die Idee-Datei schreiben
