# App-Brief: Vorlage zum Ausfüllen

> Neutrale Vorlage für jede App- oder Spielidee. Kopieren, ausfüllen, an Claude zurückgeben, dann gemeinsam iterieren.
> Aufgebaut aus bewährten Methoden: Lean Canvas, Jobs-to-be-Done, User Stories, MoSCoW, Shape Up ("Appetite", "No-Gos"), Amazon PR/FAQ, Pre-Mortem.

## So benutzt du die Vorlage

- **Nicht alles ausfüllen.** Mit Teil A (5 Minuten) anfangen, das reicht für das erste Gespräch. Teil B nach und nach, sobald die Idee trägt.
- **★ = wichtig.** Diese Felder machen den größten Unterschied für ein gutes Ergebnis.
- **"Weiß nicht" ist eine gute Antwort.** Schreib `?` oder `Claude entscheiden`. Offene Punkte sind wertvoller als geratene.
- **Beispiele schlagen Beschreibungen.** "Wie bei App X, wenn man Y macht" ist oft klarer als drei Absätze.
- **Stichpunkte reichen.** Sprachnotizen-Stil ist ok.
- Steckst du fest: Teil C (Kreativ-Starter) hilft, eine Idee überhaupt erst zu formen.

# Teil A: Ideen-Blitz (5 Minuten)

Das Minimum, um eine Idee festzuhalten, bevor sie weg ist.

```
Arbeitstitel:        ______________________________________

★ In einem Satz:     Eine App, mit der [WER] [WAS TUN] kann,
                     damit [WELCHER NUTZEN] – anders als [BISHERIGE LÖSUNG],
                     weil [DER KNIFF].

★ Auslöser:          Mir kam die Idee, als ____________________________

★ Der beste Moment:  Der Moment, in dem die App sich richtig gut anfühlt, ist,
                     wenn ________________________________________________

Typ:                 [ ] Werkzeug/Produktivität  [ ] Spiel  [ ] Social/Community
                     [ ] Lernen  [ ] Gesundheit/Gewohnheit  [ ] Marktplatz  [ ] Sonstiges: ____

Ähnlich wie:         ______________ , aber ______________________________

Bauchgefühl (1–5):   Spaß/Nutzen ___   Würde ich selbst nutzen ___
```

# Teil B: Vollständiger Brief

## 1. Problem und Zielgruppe

**★ 1.1 Welches Problem oder welcher Wunsch steckt dahinter?**
Was nervt, fehlt oder wäre schöner? Aus Sicht des Nutzers, nicht der App.
> 

**★ 1.2 Für wen genau?** (Je konkreter, desto besser. Nicht "alle".)
- Alter / Lebenssituation:
- Technik-Affinität (niedrig / mittel / hoch):
- Bin ich selbst Zielgruppe? Kenne ich 5 echte Leute, die es nutzen würden?
> 

**1.3 In welcher Situation wird die App benutzt?**
Wo, wann, wie lange, alleine oder mit anderen, unterwegs oder am Schreibtisch?
> Beispiel: "Abends auf dem Sofa, 5 Minuten, eine Hand frei"

**★ 1.4 Job-to-be-done** (Lückentext)
> Wenn ich ____________ (Situation), will ich ____________ (Motivation), damit ich ____________ (Ergebnis).

**1.5 Was nutzen die Leute heute stattdessen?** (andere Apps, Excel, Zettel, WhatsApp-Gruppe, gar nichts)

# Teil C: Kreativ-Starter (wenn noch keine fertige Idee da ist)

Kurze Lückentexte und Fragen, um eine Idee anzustoßen oder eine bestehende zu drehen. Einfach ein, zwei Muster nehmen und spontan ausfüllen, ohne zu bewerten.

### C1. Mashup: "X für Y" / "X trifft Y"
> ______________ (bekannte App/Spiel) für ______________ (neue Zielgruppe/Situation)
> ______________ trifft ______________

Beispiele: "Strava für Lesen", "Wordle trifft Geografie".

### C2. Alltagsärger
> Jedes Mal, wenn ich ______________, nervt mich, dass ______________.
> Meine Freunde/Familie lösen das gerade mit ______________ (WhatsApp, Excel, Zettel …).

### C3. "Wie könnten wir …?" (How might we)
> Wie könnten wir ______________ (Zielgruppe) helfen, ______________ (Ziel), ohne dass ______________ (typisches Hindernis)?

### C4. Was wäre, wenn …
> Was wäre, wenn ______________ (langweilige Sache) so viel Spaß machen würde wie ______________?
> Was wäre, wenn ______________ nur 30 Sekunden am Tag dauern würde?
> Was wäre, wenn man ______________ nur zusammen mit einem Freund tun könnte?

### C5. SCAMPER – eine bestehende App gezielt verändern
Nimm eine App/ein Spiel, das du kennst: ______________

| Hebel | Frage | Meine Antwort |
|---|---|---|
| **S**ubstitute | Was ersetzen (Zielgruppe, Thema, Material)? | |
| **C**ombine | Mit was kombinieren? | |
| **A**dapt | Was aus einem anderen Bereich übernehmen? | |
| **M**odify | Was extrem vergrößern/verkleinern/beschleunigen? | |
| **P**ut to other use | Für was ganz anderes nutzen? | |
| **E**liminate | Was weglassen, bis nur der Kern übrig ist? | |
| **R**everse | Was umdrehen (Rollen, Reihenfolge, Ziel)? | |

### C6. Trend × Bedürfnis
Eine Spalte links, eine rechts kombinieren:

| Neue Möglichkeit | × | Menschliches Bedürfnis |
|---|---|---|
| KI, Kamera/AR, Standort, Wearables, Widgets, Sprachsteuerung, … | | Anerkennung, Zugehörigkeit, Neugier, Kontrolle, Sammeln, Wettbewerb, Ruhe, Selbstverbesserung, … |

> ______________ × ______________ = Idee: ______________

### C7. Die Pressemitteilung (Amazon "Working Backwards")
Stell dir vor, die App ist fertig und erfolgreich:
> **Schlagzeile:** ______________ startet ______________, mit dem man endlich ______________ kann.
> **Ein Nutzer sagt:** "Früher habe ich ______________. Jetzt ______________."

### C8. Die Freundes-Frage
> Welche App würde ich meinen 3 besten Freunden heute sofort schicken, wenn es sie gäbe? ______________
> Was würde ich dazuschreiben? "______________"
